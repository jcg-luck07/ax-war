# 실행·재현 방법 (제출 양식 5번에 옮길 내용)

## 준비 (한 번만)

1. Node.js 20 이상, Docker Desktop 설치. Docker Desktop을 켜 둔다 (로그인 불필요).
2. 프로젝트 폴더에서:

```bash
npm install
npm run setup
npm run db:up
```

3. `.env.local`의 `DATABASE_URL=` 줄 주석(`#`)을 지운다 (이미 지워져 있으면 생략).
4. 원본 CSV를 DB로 복사한다 (원본 파일은 읽기만 한다):

```bash
node scripts/ingest.mjs
```

## 실행

```bash
npm run dev
```

http://localhost:3000 → 왼쪽 메뉴 **시연 도구** → `W02 안건 불러오기`.

## 시험 (화면 없이 전체 흐름 검증)

```bash
node scripts/test-rules.mjs
node scripts/test-metrics.mjs
node scripts/test-cash.mjs
node --import ./scripts/_register.mjs scripts/test-engine.mjs
node --import ./scripts/_register.mjs scripts/test-w02.mjs
node --import ./scripts/_register.mjs scripts/test-w01.mjs
```

> engine·w02·w01 시험은 로컬 DB의 안건·이력·승인·작업을 지우고 시작한다 (원본 복사본은 유지).

## 세 가지 상황 시연 순서

| 상황 | 화면에서 | 확인할 것 |
|---|---|---|
| 정상 | 안건 → 혜인 전속계약 → 역할 `Masil 대표`로 승인(거부) → `CEO/이사회`로 승인 → 후속 작업 3개 완료 | 권한 거부, 상태 변경, 작업 생성, 안건 닫힘, 이력 |
| 조건 변경 | 같은 안건(승인 전)에서 조건 변경 `20` → 결론 유지, `8` → 확정 불가·확인 요청 2건 | 승인권자 변경, 기존 승인 요청 대체 |
| 정보 부족·거절 | 확인 요청에 모의 회신(지급일 `2026-09-15` 등), 기안 일괄 회신, 대표 부결 → 재검토 작업 → 재상신 | 재평가, 일괄 반영, 거절 후 후속 작업 |
| 다른 부서 영향 | 현금 하회 구간 안 기안 → 재무 확인 요청에 집행일 `2026-08-24` 회신 | 승인권자가 그룹 CEO에서 낮아짐 |

재시연 전에는 **시연 도구 → 모두 초기화**.
