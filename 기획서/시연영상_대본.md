## 1. 녹화 전 준비 (한 번만)

1. 로컬 켜기: Docker Desktop → `npm run db:up` → `npm run dev` → http://localhost:3000
2. **DB를 원본 안건 26건으로 초기화** (리허설 후에도 매번 이 명령으로 되돌려요):
   ```bash
   node --import ./scripts/_register.mjs scripts/seed-original.mjs
   ```
3. 시연용 서류 미리 받아 압축 풀기: 기안 접수 → 캠페인 집행 → "시연용" 상자의 **정상파일 내려받기** / **데이터누락파일 내려받기** → 각각 풀어서 바탕화면 `정상`, `누락` 폴더에 두기 (영상에서는 내려받기 클릭만 보여주고, 파일 선택 창에서는 이 폴더를 열어요).
4. 사전 진행(화면에 안 찍는 부분): **혜인 전속계약(안건 26)** 을 재무팀 → 계약 담당 단계까지 먼저 넘겨 두기. 장면 4를 CEO/이사회 승인 화면에서 바로 시작하려는 거예요. (재무: 300억 `대상 아님` 선택·체크 3개·`계약 담당으로 회부 후보로 넣기` → 안건 목록 위 *미확정 안건*에서 **확정하기** / 계약 담당: 체크·계약서 첨부·회부 후보 → 확정)
5. 화면: 브라우저 1920×1080, 확대 110% 권장, 오른쪽 위 **시험 계정** 드롭다운이 잘 보이게. 알림·탭 정리.
6. 녹화: OBS 또는 Win+G(게임 바). **화면은 소리 없이 먼저 녹화 → 해설은 따로 녹음 → 편집기(Clipchamp·CapCut 등)에서 합치기**를 권해요. AI가 읽고 판단하는 시간(20~40초)이 있어서 해설을 실시간으로 맞추기 어렵기 때문이에요.
7. 빨리 감기 구간에는 화면 아래에 자막 `빨리 감기 ×4 (실제 소요 약 30초)` 처럼 넣기.

> ⚠ 로컬에서 녹화하세요. 배포본(심사에 쓰이는 DB)에서 승인·종결까지 진행하면 심사 때 쓸 안건이 소진돼요.
