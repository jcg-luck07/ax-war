# 합성 데이터 빈 양식

합성 문서(계약서·기안서·추계서)를 만들 때 채워 쓰는 **빈 양식**이에요. 계약서·기안서는 워드(docx)이고, 비용편익추계서는 실무처럼 **엑셀(xlsx)** 이에요. 종이 양식은 안에는 앱·파일 이름 같은 시스템 용어를 넣지 않았어요. 고쳐 쓸 원문(md)은 `원문_편집용/`에 있어요. 원본 데이터(`01_참가자_배포용/04_원본데이터`)는 건드리지 않고, 모든 값은 가상이어야 해요(실제 개인정보 금지).

| 파일 | 분량 | 앱에 올릴 때의 첨부 종류 |
|---|---|---|
| `01_표준계약서_인플루언서_전속계약_빈양식.docx` | 3쪽 안팎 | 기존 계약서 (갱신은 필수) |
| `02_표준계약서_캠페인_계약_빈양식.docx` | 2쪽 안팎 | 기존 계약서 (확대는 필수) |
| `03_기안서_빈양식.docx` | **1쪽** | 기안서 (필수) |
| `04_비용편익추계서_빈양식.xlsx` | 엑셀 1장 | 비용 및 성과 추계서 (필수) |

## 문서마다 담는 내용
- **계약서**: 당사자 사이의 약속만 (당사자·기간·보수·전속 조건·의무·해지·권리·분쟁·변경). 승인 경로나 현금 영향 같은 내부 판단 정보는 기안서에 적어요.
- **기안서**: 요청, 판단 근거, 대안·제약, 부족한 정보와 보충 계획, 결재. 이것만 있으면 승인권자가 판단할 수 있게 필수 정보만 담았어요.
- **비용편익추계서**: 엑셀 한 장. 노란 칸만 입력하면 회색 칸(GMV, 순매출, 제품 원가=주문당 단가×주문 수, 채널 수수료=GMV×수수료율, 공헌이익, ROAS)이 수식으로 자동 계산돼요. 공식 지표(원본 정의의 공헌이익·실질 ROAS)와 판단 보충용(5번: 연 고정 피·성과 피 반영, 자체 정의) 구역이 나뉘어 있어요. 시나리오, 현금 하회 구간, 그룹 300억 대상 칸은 목록에서 골라요.

## 기준 (세 문서가 같아야 해요)
- 성과 피는 귀속 GMV(쿠폰 반영 후·VAT 제외) 기준, 귀속 방식은 last-click 7일로 고정이에요.
- 요청금액 = 계약서 금액 합계. 캠페인은 추계서 마케팅 지출 합계와 같고, 전속계약은 고정 피 + 연 예상 성과 피(추계서 5번 구역)예요. 전속계약의 공헌이익(4번)에는 건별 마케팅 지출만 넣어요.
- 원가는 환불돼도 회수하지 않아요 (원본 정의).
- 모르는 값은 비워 두지 말고 "미확인"으로 적고 기안서 5항(부족한 정보)에 올려요.
- 승인권자를 정하는 값(계약 체결 기한, 지급 예정일, 현 계약 만료일, 그룹 300억 대상 여부, 현금 하회 구간 여부)은 기안서에 꼭 적어요.

## 참고
- 구성은 연예·광고 분야의 일반적인 계약서 틀과 이 프로젝트의 업무 문서를 참고했어요. 특정 표준 계약서를 그대로 옮긴 것이 아니라서, 실제 사용 전에는 법무 검토가 필요해요.
- 주민등록번호는 넣지 않았어요 (생년월일과 미성년자 여부만).
- 통보 기록과 통보 수령 증빙(회신)은 계약서가 아니라 별도 통지서·회신 문서예요.
- 승인·부결 뒤 금액이 바뀌는 수정 보고는 기안서를 다시 쓰지 않고, 앱의 수정 보고 기능으로 원 금액 → 수정 금액과 추가 첨부만 더해요.
