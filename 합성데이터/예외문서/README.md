# 예외 상황 합성 서류

정상 안건(`합성데이터/채운문서` T01~T30)의 **계약서·추계서**를 바탕으로 만든 예외 서류예요. 폴더 이름 끝의 `T##`가 바탕 안건이에요. **각 폴더에 그 안건의 서류가 한 벌 다 들어 있어요** — 문제가 있는(바뀐) 서류는 `_금액변경`·`_누락`이 붙은 파일이고, 나머지 문제없는 서류는 `채운문서`의 원본 파일 그대로예요 (바뀐 서류의 원본은 빼고 바뀐 파일로 대신했어요).
값은 모두 가상이고 원본 데이터는 건드리지 않았어요.

## C. 조건 변경 — 계약금액이 바뀐 계약서·추계서

계약금액만 바뀌고 나머지는 모두 원래 서류와 같아요. 안건에서 **바뀐 계약금액만 다시 입력하면** 공헌이익·ROAS 등 계산식이 그에 맞게 바뀌어요 (예상 GMV·원가·수수료·반품 같은 다른 입력은 그대로).
수정 보고에서는 이 계약서·추계서를 **추가 첨부**로 올려요. 승인 뒤 최종 종결 전이라 승인권자는 최초 결정한 사람이 그대로예요.

| 폴더 | 바탕 안건 | 대상 | 금액 변경 | 계산 결과 | 확인할 점 |
|---|---|---|---|---|---|
| [C01](C01_금액변경_신규_토모카_캠페인4_T03) | T03 | 토모카 색조 캠페인4 (신규) | 요청금액(= 계약서 건별 계약금액) 12,500,000원 → 12,000,000원 (−4.0%) | 공헌이익 4,804,550원 → 5,304,550원 | 변동 5% 이내 → 수정 보고는 최초 승인권자(Masil 대표)에게 바로. 1천만 원 초과 상태 그대로. |
| [C02](C02_금액변경_신규_초혜핏_캠페인5_T11) | T11 | 초혜핏 색조 캠페인5 (신규) | 요청금액(= 계약서 건별 계약금액) 45,000,000원 → 36,000,000원 (−20.0%) | 공헌이익 191,735,440원 → 200,735,440원 | 변동 5% 초과 → 재무팀 절차부터 다시. 기안 묶음 총액도 1.35억 → 1.26억 원(여전히 1억 초과). |

| [C04](C04_금액변경_신규_MiaSkin_캠페인3_T06) | T06 | Mia Skin 색조 캠페인3 (신규) | 요청금액(= 계약서 건별 계약금액) 10,000,000원 → 10,400,000원 (+4.0%) | 공헌이익 13,907,200원 → 13,507,200원 | 정확히 1천만 원(전결)이던 금액이 +4%로 1천만 원을 넘음 — 기준을 넘나들어도 승인권자는 유지. |
| [C05](C05_금액변경_전속_토모카_갱신_T16) | T16 | 토모카 전속계약 갱신 | 연 고정 피 800,000,000원 → 700,000,000원 → 연 계약금액 합계 800,000,000원 → 700,000,000원 (−12.5%) | 5번 구역(고정 피·성과 피 반영) −586,612,050원 → −486,612,050원 (공식 공헌이익은 그대로) | 전속계약 갱신. 연 고정 피 인하 → 연 계약금액 합계가 줄고 5번 구역 값이 바뀜. |

바뀐 서류는 `03_표준계약서_…_금액변경.docx`(금액만 바뀐 계약서)와 `02_비용편익추계서_금액변경.xlsx`(바뀐 금액이 반영된 추계서)예요. 기안서(`01_`)와 기존 계약서(`04_`)는 원본 그대로 들어 있어요.

## M. 값 누락 — 계약서나 추계서의 칸이 비어 있음

서류 안의 일부 칸이 `[          ]`(계약서·docx)이거나 입력 칸이 비어 있어요(추계서·xlsx, 계산 결과도 비어 보여요). 정보 부족 상황을 시험해요 — 값을 지어내지 않고 비워 두거나, 확인 요청·보완 요청으로 이어져야 해요.
